  • Survive the bad dayWhat failure must we survive, and how fast do we recover?16
    • Stay up (high availability)Server, rack or datacentre fails3
      • Availability setsspread across racks

        VMs spread over fault domains (power, network) and update domains (maintenance) in one datacentre.

        Use it whenThe region has no zones, or the app needs very low latency between VMs; 99.95% for two or more VMs.
        Look elsewhere whenYou must survive a whole datacentre failing: use zones.
        Exam wordsfault domainupdate domain99.95%rack failure
        Module 08 · High availability →
      • Availability zonesspread across buildings

        Physically separate datacentres within a region. Services are zonal (pinned) or zone-redundant (spread for you).

        Use it whenSurvive a datacentre failure; 99.99% for VMs across zones; zone-redundant SQL, App Service, storage.
        Look elsewhere whenYou must survive a region loss: add a second region.
        Exam wordsdatacentre failure99.99%zone-redundantzonal

        Meridian Zones everywhere they exist for Tier 1 and Tier 2.

        Module 08 · High availability →
      • Region pairsa partner city

        Two regions in one geography linked for sequential updates, platform recovery priority and GRS replication.

        Use it whenChoosing the DR region and the GRS target.
        Look elsewhere whenThe region has no pair, or residency rules require a different secondary: choose it yourself.
        Exam wordspaired regionregional disastergeo-redundant

        Meridian Central India ↔ South India; Germany West Central ↔ Germany North.

        Module 08 · High availability →
    • Go back in time (backup)Deletion, corruption, ransomware8
      • Recovery Services vaultVMs, Files, SQL in VMs

        Azure Backup vault for Azure VMs, SQL Server and SAP HANA in VMs, Azure Files, MARS and MABS; also home to Site Recovery.

        Use it whenBacking up IaaS VMs, file shares and databases running inside VMs.
        Look elsewhere whenBlobs, managed disks, PostgreSQL or AKS: use a Backup vault.
        Exam wordsAzure VM backupAzure Files backupSQL in VMMARS agent

        Meridian One per region, GRS with Cross Region Restore; Enhanced policy for PCI VMs.

        Module 08 · Azure Backup →
      • Backup vaultblobs, disks, PostgreSQL, AKS

        The newer vault type for Azure Blobs (operational and vaulted), Azure Disks, Database for PostgreSQL and AKS.

        Use it whenProtecting blobs and managed disks; new datasources.
        Look elsewhere whenAzure VMs or Azure Files: Recovery Services vault.
        Exam wordsblob backupdisk backupAKS backup

        Meridian Operational + vaulted backup for invoices; Disk Backup for standalone data disks.

        Module 08 · Azure Backup →
      • Cross Region Restorerestore in the paired region

        On a GRS vault, lets you restore to the secondary region whenever you choose.

        Use it whenBackup-and-restore DR, and regional drills.

Mindset takeaway

Three questions sort almost every Part III item. Which failure? (rack, datacentre, region, or the data itself) picks sets, zones, DR or backup. How much do we manage? picks VMs, containers, App Service or Functions. Must the sender wait, or is it just news? picks a call, a queue or an event.
