  • Build the networkWhat are the roads, and who may use them?10
    • Address spaceYour private colony2
      • Virtual network and subnetsone region, your address space

        An isolated private network in one region, defined by CIDR address spaces and divided into subnets; 5 addresses reserved per subnet.

        Use it whenEvery IaaS and most private PaaS designs; plan non-overlapping ranges for the whole company.
        Exam wordsaddress spacesubnet5 reserved addressesoverlap

        Meridian 10.10/16 Central India, 10.20/16 South India, 10.30/16 Germany West Central.

        Module 11 · Virtual networks →
      • NAT Gatewayexplicit outbound internet

        Outbound internet for a subnet through fixed public IPs, with plenty of SNAT ports.

        Use it whenAllow-listable egress IPs; replacing default outbound access.
        Look elsewhere whenInbound traffic: use a load balancer or gateway.
        Exam wordsoutboundfixed egress IPSNAT exhaustion

        Meridian On the firewall subnet for SNAT scale.

        Module 11 · Virtual networks →

        Use it whenSegmenting subnets: web may talk to app, app to data.
        Look elsewhere whenFQDN filtering or central inspection: Azure Firewall.
        Exam wordsportsubnetpriorityservice tag
        Module 11 · NSGs and ASGs →
      • Application security groupsrules by role, not IP

        Group NICs by role so NSG rules say "web → db" instead of IP lists.

        Use it whenRules that survive scaling and re-addressing.
        Exam wordsgroup VMs by role
        Module 11 · NSGs and ASGs →
      • Flow logs and IP flow verifywhy was it blocked?

        Network Watcher tools: VNet flow logs with Traffic Analytics, IP flow verify, effective rules.

        Use it whenTroubleshooting and auditing traffic.
        Exam wordsIP flow verifyflow logsTraffic Analytics

    • TopologyHow networks connect to each other5
      • VNet peeringa private road between two VNets

        Low-latency connection over the Microsoft backbone, same or different regions; not transitive.

        Use it whenConnecting spokes to a hub, or two VNets directly.
        Look elsewhere whenAddress spaces overlap: re-address first.
        Exam wordsbackbonenot transitiveglobal peering
        Module 11 · Topology →
      • Hub and spokeyou build the ring road

        A hub VNet with shared services (firewall, gateways, Bastion, DNS) peered to workload spokes; UDRs route via the hub.

        Use it whenOne or two regions, custom routing, NVAs.
        Look elsewhere whenHundreds of branches and many regions: Virtual WAN.
        Exam wordshubshared servicesuser-defined routes
        Module 11 · Topology →
      • Virtual WANMicrosoft runs the ring road

        Managed hubs with built-in routing, VPN, ExpressRoute and secured-hub firewalls; any-to-any across hubs.

        Module 11 · Topology →
      • Virtual Network Managergovern many VNets centrally

Mindset takeaway

For networking, read the requirement for protocol (HTTP or not), scope (one region or global) and path (internet, private line, private IP). For migration, read for what moves (server, database, files) and how much downtime or bandwidth you have. Those words pick the leaf.
