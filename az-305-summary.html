A Comprehensive Guide to Microsoft Azure Services

Navigating the vast ecosystem of Microsoft Azure can be a challenge. This guide consolidates key services and documentation from official Microsoft learning paths, focusing on core concepts for solutions architects and administrators.

This document is structured to provide a clear overview of different service categories, with direct links to official documentation and hands-on lab simulations to deepen your understanding.

Governance & Compliance (Module 1)

Establishing a strong governance framework is the first step in any Azure journey. It ensures your cloud environment is secure, compliant, and well-managed.

  • Management Group: A container for subscriptions that allows you to apply policies and access control at a higher level. Learn more about Management Groups.
  • Subscription: A logical container for your Azure services that provides a billing boundary. See documentation on Azure Subscriptions.
  • Resource Group: A container that holds related resources for an Azure solution. A Resource Group provides a lifecycle boundary for the contained resources. Read about Resource Groups.
  • Azure Tag: A key-value pair used to categorize resources for management and billing purposes. Learn to tag resources.
  • Azure Policy: A service that helps you enforce organizational standards and assess compliance at scale. Explore the overview of Azure Policy.
  • RBAC (Role-Based Access Control): A system for managing access to Azure resources. Learn about RBAC.
  • Azure Blueprint: A service that defines a repeatable set of Azure resources that implement an organization's standards. Discover the overview of Azure Blueprints.

Compute Services (Module 2)

Azure offers a wide range of compute options, from virtual machines to serverless functions, to meet any application need.

  • VM Scale Set: A service for managing a group of identical, load-balanced virtual machines. Learn about VM Scale Sets orchestration modes.
  • Azure Batch: A service for running large-scale parallel and high-performance computing (HPC) applications efficiently in the cloud. Read the technical overview of Azure Batch.
  • Azure Container Instances (ACI): A fast and simple way to run containers in Azure without managing virtual machines. See the quickstart for ACI.
  • Azure Container Registry (ACR): A private registry for building, storing, and managing Docker and Open Container Initiative (OCI) images. Learn about ACR.
  • App Service: A platform for building and hosting web apps, mobile backends, and REST APIs. View the App Service lab simulation.
  • Azure Functions: A serverless compute service that lets you run code triggered by an event without explicitly provisioning or managing infrastructure. See Azure Functions scenarios.
  • Azure Logic App: A service for automating workflows and business processes. Read about Logic Apps.

Storage Solutions (Module 3)

Azure provides robust and scalable storage options, from simple blob storage to file shares and specialized data lakes.

  • Storage Account: A container that holds all your Azure Storage data objects. See the Storage Account introduction.
  • Type of Disk: Azure offers different types of disks for virtual machines, including Standard HDD, Standard SSD, Premium SSD, and Ultra Disk. Learn about disk types.
  • Immutable Storage: A feature that allows you to store data in a write-once, read-many (WORM) state for data retention and compliance. Read the overview of immutable storage.
  • Data Lake Storage Gen2: A scalable and secure data lake solution built on Azure Blob Storage. Learn about Data Lake Storage Gen2.
  • Azure Files: A service that offers managed file shares in the cloud. See the introduction to Azure Files.
  • NetApp Files: A service that provides enterprise-grade, high-performance file storage. Get started with Azure NetApp Files.

Database Solutions (Module 4)

Azure provides a variety of database services, from relational SQL databases to globally distributed NoSQL solutions.

  • Azure SQL Database: A managed relational database service in Azure. Explore the documentation for Azure SQL Database.
  • Azure SQL Edge: A small-footprint, edge-optimized SQL database engine. See the full documentation for Azure SQL Edge.
  • Azure Cosmos DB: A globally distributed, multi-model database service. Learn about Azure Cosmos DB.
  • Database Modernization: A guide to help you transition your databases to the cloud. Read the database modernization guide.

Big Data & Analytics (Module 5)

Analyze and transform massive datasets with Azure's powerful big data services.

  • Azure Data Factory: A service for creating and orchestrating data-driven workflows for data integration. Explore Data Factory documentation.
  • Azure Databricks: A fast, easy, and collaborative Apache Spark-based analytics service. See the Databricks documentation.
  • Azure Synapse Analytics: A unified analytics service that brings together enterprise data warehousing and big data analytics. Learn about Azure Synapse Analytics.
  • Azure Stream Analytics: A real-time analytics service for processing fast-moving streams of data. Read about Stream Analytics solutions.

Messaging & Integration (Module 6)

Connect applications and services with reliable and scalable messaging solutions.

  • Azure Queue Storage: A simple and durable message queue service. Read the introduction to Queue Storage.
  • Azure Service Bus: A reliable messaging service for connecting applications, services, and devices. Learn about Service Bus Messaging.
  • Azure Event Hubs: A highly scalable data streaming platform and event ingestion service. Explore the Event Hubs documentation.
  • Azure Event Grid: A service that enables you to build event-driven applications with a pub/sub model. Read the Event Grid overview.
  • IoT Hub: A managed service that acts as a central message hub for bidirectional communication between IoT applications and the devices it manages. Discover IoT Hub concepts.
  • Azure API Management: A service for publishing, securing, and analyzing APIs. Learn about API Management concepts.

Identity & Security (Module 7)

Secure your cloud environment with Azure's comprehensive identity and access management services.

  • Entra ID: The identity and access management solution for Azure. See documentation on Identity and Access Management.
  • Conditional Access: A feature of Entra ID that enables you to enforce policies to protect your cloud apps. Read the Conditional Access overview.
  • Entra ID Protection: A tool that allows you to detect, investigate, and remediate identity-based risks. Learn about Entra ID Protection.
  • Managed Identity: A feature that provides an identity for your Azure service, removing the need to manage credentials. Read the Managed Identity overview.
  • Azure Key Vault: A service for securely storing and managing secrets, keys, and certificates. Explore the Key Vault documentation.

Monitoring & Operations (Module 8)

Gain deep insights into your applications and infrastructure with Azure's monitoring tools.

  • Azure Monitor: A comprehensive solution for collecting, analyzing, and acting on telemetry data. See the Azure Monitor overview.
  • Log Analytics: A service that allows you to query and analyze logs collected by Azure Monitor. Learn about Log Analytics.
  • Azure Workbooks: A flexible canvas for data analysis and the creation of rich visual reports. Read the Workbooks overview.
  • Azure Insights: A service that monitors the performance and availability of your live web applications. Learn about Application Insights.
  • Azure Data Explorer: A fast and highly scalable data exploration service for log and telemetry data. See the Azure Data Explorer service page.

Networking (Module 9)

Connect your resources and secure your network with Azure's robust networking services.

  • Azure Virtual Networks (VNETs): The fundamental building block for your private network in Azure. Read the Virtual Networks documentation.
  • Hub & Spoke Model: A popular network topology for managing connectivity and security. Learn about the hub-spoke model.
  • Azure Firewall: A managed, cloud-based network security service that protects your Azure Virtual Network resources. See the Azure Firewall overview.
  • Load Balancer: A service that distributes incoming traffic among healthy virtual machines. Explore the Load Balancer documentation.
  • Application Gateway: A web traffic load balancer that enables you to manage traffic to your web applications. Learn about Application Gateway.
  • Traffic Manager: A DNS-based traffic load balancer that enables you to distribute traffic to public-facing applications across global Azure regions. Read about Traffic Manager.
  • Azure Front Door: A scalable and secure entry point for fast delivery of global web applications. See the Front Door overview.
  • Network Security Groups (NSGs): A service that filters network traffic to and from Azure resources. Read the NSG overview.
  • DDoS Protection: A service that protects your applications and resources from distributed denial of service attacks. Learn about DDoS Protection.

Backup & Disaster Recovery (Module 10)

Ensure business continuity with Azure's native backup and disaster recovery solutions.

  • Azure Backup: A service for backing up data in Azure and on-premises to the cloud. Explore Azure Backup.
  • Point-in-time restore in Blob Storage: A feature that lets you restore a block blob to an earlier state. Learn about point-in-time restore.
  • Azure Site Recovery: A service that ensures business continuity by keeping business apps and workloads running during outages. See the Site Recovery overview.

Migration & Adoption (Module 11)

Plan and execute your cloud migration with the Cloud Adoption Framework and specialized tools.

  • Cloud Adoption Framework: A set of guidelines to help you create and implement strategies for cloud adoption. Read the Cloud Adoption Framework.
  • Azure Migrate: A service that helps you assess and migrate on-premises workloads to Azure. Explore the Azure Migrate documentation.
  • Azure Database Migration Service: A service that enables seamless migration of databases to Azure. Learn about DMS supported scenarios.
  • Azure File Sync: A service that allows you to centralize your organization's file shares in Azure Files. See the Azure File Sync planning guide.
  • Data Box: A family of products that helps you transfer large amounts of data to Azure. Read the Data Box overview.
